Invoicing Configuration

Expand
Pre-Config Checklist
  • 1
    Install all l10n_mx modules In Apps, install Mexican Localization (l10n_mx, l10n_mx_edi) to enable CFDI 4.0 engines.
  • 2
    Complete Company Info (RFC = Tax Number) Ensure Company Legal Name, Postal Code (CP), Fiscal Regime, and Tax Number (RFC) match SAT records exactly.
  • 3
    Company must be registered with the SAT The legal entity and RFC must be active and authorized to issue electronic invoices on the official SAT portal.
  • 4
    Testing PAC: SOLUCION FACTIBLE (NO user/password) For testing/sandbox mode, select Solución Factible as the PAC and leave username & password completely empty.
Side Note Products must have a UNSPSC Category (found under the Accounting tab in the product form) in order to invoice.

Payroll Configuration

Expand
Payroll Setup Checklist
  • 1
    Install all 3 Payroll Modules (l10n_mx_hr_payroll*) In Apps, install l10n_mx_hr_payroll, l10n_mx_hr_payroll_account, and l10n_mx_hr_payroll_account_edi (auto-installs all three).
  • 2
    Complete Company Info (Address, RFC, IMSS) In Settings → Companies, ensure Legal Name, Full Address (sets default state payroll tax), RFC, MXN, and Registro Patronal / Risk Class are filled.
  • 3
    Complete Employee Profiles & Contracts (Fill Out Thoroughly) In Employees, configure Work Address, Trusted Bank Account (mandatory), RFC, CURP, NSS (IMSS), Wage Type, and Regime Type.
  • 4
    Configure INFONAVIT / FONACOT Tab Mexico Specific 🇲🇽
    🇲🇽 What is this in Mexico?
    Statutory Credits
    🏠 INFONAVIT (Housing Institute):

    Affordable mortgage loan deductions from paychecks (Fixed Fee, %, or Discount Factor).

    💳 FONACOT (Consumer Credit):

    Low-interest government consumer loan deductions as a fixed monthly amount.

    ⚠️ Crucial Rule: Switch status to "Closed" once paid off to stop deductions.
    Read official documentation ↗
    Set statutory housing (INFONAVIT) or consumer loan (FONACOT) retentions; mark status as "Closed" once paid off. Docs ↗
  • 5
    Payslip Stamping (Timbrado de Nómina) Uses company SAT CSD Certificate and configured PAC to stamp payslips and generate signed XML + PDF.

SII Electronic Invoicing & Localization

Expand
Prerequisites & Setup Checklist
  • 1
    Install Chile Localization Modules In Apps, install l10n_cl, l10n_cl_edi (DTE Invoicing), l10n_cl_edi_stock (Guías DTE 52), and l10n_cl_reports (F29 tax report).
  • 2
    Configure Company RUT & Giro Comercial In Settings → Companies, ensure Legal Name, RUT with Módulo 11 check digit (e.g. 76.123.456-K), and exact official Giro registered at SII are specified. Add Resolution Number and Date.
  • 3
    Upload Digital Certificate (.pfx / .p12) In Accounting → Configuration → Settings → Chile Localization, upload the authorized taxpayer's personal certificate and enter the password. This digitally signs every XML envelope (EnvioDTE).
  • 4
    Select the SII Web Services Environment 3 Connection Types
    In Accounting ‣ Configuration ‣ Settings ‣ Chile Localization under Electronic invoice data
    View 3 Modes
    • SII - Test
    Test Certification

    For test databases using test CAFs obtained from the SII. In this mode, the direct connection flows can be tested, with the files being sent to the SII.

    • SII - Production
    Official Production

    For production databases. Every issued DTE is legally valid and officially registered with the tax authority.

    • SII - Demo Mode
    Internal Simulation (No External Send)

    Files are created and accepted automatically in demo mode but are not sent to the SII. For this reason, rejection errors or Accepted with Objections will not appear in this mode. Every internal validation can be tested in demo mode. Avoid selecting this option in a production database.

  • 5
    Customer Intercambio Email Server Configure incoming and outgoing mail server dedicated to B2B DTE exchange (envio_dte@empresa.cl) to dispatch EnvioDTE XML envelopes and receive buyer receipts automatically.
