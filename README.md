# Odoo LATAM Knowledge & Standard Flows Hub

Ultra-lightweight internal portal with Odoo branding, instant country filtering, 30-sec TL;DRs, video timestamps, and standard flow loops.

## How to Use
Double-click index.html to launch immediately in your browser.

## Adding New Cards
Click + Add Card in the top navigation bar to add custom flows or error fixes without touching code.

## Weight Optimization
Use WebM/MP4 loops or lightweight GIFs (<1MB) for standard flow recordings.
